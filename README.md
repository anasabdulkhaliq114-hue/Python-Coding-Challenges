A collection of practical Python applications built to strengthen my core programming skills, conditional logic, data structures (lists), and randomization.

## Included Projects
1. **book_library.py** — A CLI personal library and wishlist manager using Python lists (append, remove, and membership checks).

3. **coin_guessing_game.py** — A coin toss simulator utilizing Python's random module (randint and random).
4. **grade_evaluator.py** — A student score classifier with input range validation (0–100).
